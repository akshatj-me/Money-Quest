Money Quest — private-first PWA

No personal financial values are stored in the public repository.
On first launch, the app asks for your balances, debts, salary, trip and goal details.
Those values are stored only in browser localStorage on your device.

GitHub Pages:
1. Create a public repository.
2. Upload all files from this ZIP to the repository root.
3. Settings > Pages > Deploy from a branch > main / root.
4. Open the Pages URL in Safari on iPhone.
5. Share > Add to Home Screen.

Important:
- Use Settings > Export backup occasionally.
- Do not upload your exported backup JSON to the public repository.
